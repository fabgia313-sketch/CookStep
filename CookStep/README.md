# 📁 CookStep — Dossier Projet

Application mobile Android de cuisine guidée, étape par étape.
Android • Expo + Supabase • IA Anthropic

---

## Structure du dossier

```
cookstep-project/
│
├── CLAUDE.md              ← À donner à Claude Code au début de chaque session
│
├── brief/
│   └── BRIEF.md           ← Vision, cible, fonctionnalités, roadmap
│
├── docs/
│   ├── SESSIONS.md        ← Journal de toutes les sessions (à tenir à jour)
│   └── SUPABASE.md        ← Schéma SQL + config backend
│
└── design/                ← Maquettes HTML (à compléter)
```

---

## Comment utiliser ce dossier

### Avec Claude Code (terminal)
Au début de chaque session, dire :
> "Lis le fichier CLAUDE.md et dis-moi ce que tu as compris du projet avant de commencer."

### Avec Claude.ai (chat)
Les fichiers sont uploadés dans le Projet Claude — contexte automatique à chaque conversation.
